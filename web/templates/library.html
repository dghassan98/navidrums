Music Library

A read-only index of what your Navidrome library already holds, so browse pages can show what is worth downloading. Navidrums only ever reads from Navidrome; it never modifies the library.

Library Cleanup (dry run)

Compares your library against the Qobuz catalogue and reports what it would change. It writes nothing. A full scan is thousands of throttled lookups, so it runs in the background and takes a while.

Apply Library Fixes

Writes approved changes to the files. Original values are read from the file and backed up before anything is replaced, and every write is read back to confirm it took. Start with a dry run, then a small batch, and check the result in your music server before going further.
