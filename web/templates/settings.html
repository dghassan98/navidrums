Qobuz Credentials

Used by the QOBUZ DIRECT provider. Values saved here override the matching QOBUZ_* environment variables and take effect without a restart. They are stored in the Navidrums database in plain text, so prefer the environment on a shared machine.

Leave a field blank to keep the current value. Type - to clear it and fall back to the environment.

Where do I get these? (and what to do when one stops working)

Qobuz does not issue these. They are read out of the Qobuz web player, and Qobuz rotates them, so expect to redo this occasionally. Take all three from the same browser session so they match.

App ID and App secret

Easiest way — the community tool derives both automatically: QobuzDL/Qobuz-AppID-Secret-Tool

  1. Install the one dependency: pip install aiohttp
  2. Run python main.py
  3. It prints an app_id and a secret — paste them above

It reads the current bundle from play.qobuz.com, derives the candidate secrets, and verifies each against track/getFileUrl, so the pair it prints is already known-good. No Qobuz account is needed to run it.

Manual alternative: F12 → Sources → play.qobuz.com/resources/<version>/bundle.js, pretty-print with { }, then Ctrl+F for appSecret and take the pair inside production:{api:{...}}. Ignore the "XXXXX" placeholder just above it.

Auth token

  1. Log in at play.qobuz.com
  2. F12 → Network tab, then click any track
  3. Pick a request to www.qobuz.com/api.json/0.2/...
  4. Under Request Headers, copy X-User-Auth-Token

Alternative: Application → Local Storage → https://play.qobuz.com, then find the entry containing localuser (and the corresponding auth value) and copy just that value.

Which one do I replace?

Hit Test connection — it checks each separately:

  • App secret: rejected — Qobuz rotated it. Re-read the bundle. Browsing keeps working; only downloads break.
  • Account: rejected — the token expired. Grab a fresh one.
  • App ID: rejected — re-read the bundle and take the id and secret together.

A paid subscription is required: file URLs are refused on free accounts.

QOBUZ DIRECT

The official Qobuz API, used with your own subscription. Requires QOBUZ_APP_ID, QOBUZ_APP_SECRET, QOBUZ_EMAIL and QOBUZ_PASSWORD to be set in the environment — credentials are never stored in the database. Downloads fail with a clear error until they are configured.
